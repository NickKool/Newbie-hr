# НОВИЧОК — HR Intelligence

Веб-приложение для HR-аналитики, выявления проблем адаптации и мониторинга ранней текучести персонала.

## О проекте

«НОВИЧОК» помогает HR-команде анализировать увольнения сотрудников, сравнивать показатели подразделений и выявлять потенциальные проблемы на раннем этапе.

Основная задача MVP — показать, как данные о найме и увольнениях могут использоваться для принятия управленческих решений и организации работы HR.

Все данные в демонстрационной версии синтетические и не относятся к реальным сотрудникам или показателям компании.

## Основные возможности

### 1. Панель управления

- Ключевые показатели по сотрудникам, наймам и увольнениям.
- Динамика найма и увольнений.
- Распределение увольнений по подразделениям.
- Анализ причин увольнений.
- Последние HR-сигналы.

### 2. Аналитика

- Фильтрация данных за 30 дней, 90 дней и 12 месяцев.
- Сравнение подразделений по количеству увольнений.
- Анализ ранних увольнений.
- Распределение причин ухода.
- Раздельный расчёт доли ранних увольнений среди уволившихся и среди принятых сотрудников.

### 3. Центр автоматизации

- Просмотр HR-сигналов.
- Фильтрация по типу и статусу.
- Просмотр причин возникновения сигналов.
- Управление статусами сигналов и связанных внутренних задач.
- Сохранение изменений между перезагрузками страницы.

### 4. Сотрудники

В текущем MVP раздел представлен информационным блоком. Полноценный реестр сотрудников и управление карточками адаптации не входят в объём первой версии.

## Архитектура

Приложение построено как frontend-only MVP без отдельного backend.

Основные части:

- `src/app` — приложение и навигация.
- `src/components` — общие UI-компоненты.
- `src/features` — функциональные разделы приложения.
- `src/data` — синтетические демонстрационные данные.
- `src/services` — работа с локальным хранилищем.
- `src/types` — типы данных.
- `src/utils` — вспомогательные функции.

Бизнес-метрики вынесены в отдельный модуль аналитики. UI-компоненты используют готовые расчёты, а работа с localStorage изолирована в сервисном слое.

## Демонстрационные данные

Данные генерируются детерминированно и используются для демонстрации аналитических сценариев.

Основные контрольные показатели за 12 месяцев:

- 400 активных сотрудников.
- 120 наймов.
- 36 увольнений.
- 12 ранних увольнений (стаж менее 90 дней).
- 33,3% ранних увольнений среди всех уволившихся.
- 10% ранних увольнений относительно количества наймов.

Эти показатели являются исключительно демонстрационными.

## Ограничения MVP

- Нет backend и подключения к корпоративным системам.
- Нет интеграции с Bitrix24.
- Нет внешних AI API.
- HR-сигналы и внутренние задачи представлены демонстрационными данными.
- Автоматическое выполнение бизнес-правил и создание задач в реальных системах не реализованы.
- Изменения статусов сохраняются локально в браузере.
- Полноценный реестр сотрудников и функциональность адаптации отложены на следующие этапы.

## Локальный запуск

Требования:

- Node.js
- npm

Установка зависимостей:

```bash
npm install
```

Запуск в режиме разработки:

```bash
npm run dev
```

Production-сборка:

```bash
npm run build
```

Результат сборки находится в директории `dist`.
